# Whaticket

Use as ferramentas do servidor MCP `whaticket-local` já configurado no Codex. Se o servidor estiver indisponível, informe isso ao usuário.

Para agendar uma mensagem, preserve o texto solicitado e use a data e hora no fuso de Brasília. Para contatos brasileiros, use o DDI 55 e o DDD informado. Se a ferramenta retornar explicitamente que o contato não está cadastrado e o número tiver nove dígitos após o DDD, começando com 9, tente novamente sem esse primeiro 9. Após sucesso, informe o horário e o ID retornado.
